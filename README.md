# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/KrishnaSaiTejaSandalla/Portfolio.git
```

## Navigate to Project

```bash
cd Portfolio
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```
